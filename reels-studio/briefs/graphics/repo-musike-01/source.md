# musike — README snapshot (github.com/Ernani1234/musike)

A self-hosted music player: a small server that you run fetches the stream with yt-dlp
and hands the bytes to the player. Audio and video switch mid-track from the same
position — for songs it even finds the artist's official music video.

Runs everywhere: Windows, macOS and Linux apps, Android, Android TV and iPhone apps,
an installable browser PWA, and a Docker image.

Playlists and favourites live in a local file you can export and move to any other Musike.

Usage limits, stated plainly: personal and educational use only.
The README says playing YouTube streams without ads breaks YouTube's terms;
public bots like Groovy and Rythm were shut down after notices from Google.
