# Rule map — what we took from the psychology repo

The reference repo is The Deeper Mind (Jungian psychology). We did **not** copy its niche, voice, thumbnails, or Pexels pipeline.

We kept the *production discipline*: one step per turn, repo as truth, caption sync, title/thumb split, cadence 2+3, metadata gate, Handoff-first, Shorts = hook+payoff with independent media.

Full mapping lives at the bottom of `MASTER_RULES.md`.
