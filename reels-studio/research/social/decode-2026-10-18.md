# Channel decode: 2026-10-18 — how the benchmark channels actually win

Tool: `tools/channel_decode.py` (yt-dlp + platform captions/faster-whisper + Praat/parselmouth
prosody + OpenCV frames/cuts). Sample: 9 referred TikTok benchmark accounts, latest 10 listed,
top-2 + bottom-1 by views decoded per account (27 TikTok videos; 24 with full script/voice/media),
plus Github Signals' YouTube Shorts listing (10 videos, headings/views only — YouTube full-video
fetch is bot-gated without cookies; see Limits). Raw media stays in `research/social/raw/decode/`
(git-ignored). Numbers below are medians of the decoded sample; small n — directional, not proof.

## What winners do, element by element

### Script (spoken)
- **~99–110 words in ~37 s.** Top tier median 99 words / 36.8 s; bottom 109 words / 33.4 s.
  Winners are not longer — they are denser with payoff per sentence.
- **Faster delivery wins:** top **186 wpm** vs bottom **160 wpm**. (Our scripts run 160–193 wpm;
  aim 175–190 for spotlights.)
- **Hook = a claim about the viewer's world, spoken in sentence one:** "Someone just rebuilt
  Spotify for iPhone so it looks exactly like Apple's newest music app…" — named thing +
  transformation + familiar anchor (Spotify/Apple), no channel intro, no licence, no spec sheet.
  Hook types in the top tier: named-tool-first, stop/problem and transformation dominate;
  vague "other" hooks dominate the bottom tier.
- **Spoken CTA is a winner's habit:** 62% of top-tier scripts ask for something (comment /
  follow / save) vs 33% of bottom-tier.

### Voice / TTS (the "hear" numbers)
- **Pitch range: top 16.0 semitones vs bottom 13.8.** Expressive, wide-melody delivery separates
  winners; flat reads sink. Median pitch ~132 Hz (natural male range), voiced share ~0.6
  (real pauses, not a wall of sound).
- Our Chatterbox profile measures 13.6–16 st on approved samples — we are in range; keep the
  ≥14 st ambition for hooks and verdict lines, and never ship a flat take.

### Cover / first frame (the "see" numbers)
- **The product is the cover.** github.signals' 149K video opens on the actual GitHub README —
  phone screenshots of the result fill the frame; the first spoken words land as giant
  word-by-word captions ("SOMEONE / JUST REBUILT"). No logo sting, no "hey guys".
- **Face channels use face + one symbolic visual:** dr_cintas (318K) = his face, lower half;
  a bold map/logo graphic, upper half; two-word captions. sebintel (350K) = face + a curiosity
  AI image (branded robots boxing). One idea per frame, readable muted.
- **Cuts:** top 5.2 vs bottom 4.8 cuts/10 s — a modest edge; the bigger edge is that *every*
  frame carries either the product, a face, or 2–4 giant caption words.

### Heading (title)
- Pattern: **"Name: outcome"** or a plain descriptive sentence ("Automate your Instagram
  content workflow with AI skills…", "Here is everything that happened in AI this week in
  60 seconds"). Sentence case, specific nouns, the benefit inside the title. No ALL-CAPS
  clickbait, no licence/spec words.

### Description
- On TikTok the description is a **mini-article (~400 chars median)**: it restates the hook,
  then explains the thing in keyword-rich plain sentences. Only 46% carry a link; hashtags are
  few (median 2.5). It is written for TikTok search, not as a link dump.
- Lesson for us, per platform (with PLAYBOOK §9): TikTok = keyword paragraph; YouTube Shorts =
  keyword title + 2–3 keyword sentences, link below; Instagram/Facebook = short benefit lines +
  comment-keyword CTA (sends/saves are the ranking fuel there).

## The same video, two algorithms
Github Signals posted the same Vitrine video to TikTok (**149,200 views**) and YouTube Shorts
(**228 views**). Identical script, voice, cover and heading — wildly different outcome. The
content package travels; distribution does not. Each platform's algorithm rewards different
first signals (TikTok: completion + shares on a cold audience; YouTube Shorts: click/swipe-away
rate from the Shorts feed + channel history; Instagram: sends/saves; Facebook: shares +
originality). So: adapt the *package* per platform (title, caption shape, CTA verb), never
assume a TikTok winner will transfer as-is.

## Rules adopted from this decode (folded into PLAYBOOK §1/§4)
1. First frame = the product/result (or face + one symbol). Nothing else gets frame one.
2. Word-by-word giant captions from the first spoken word; 2–4 words on screen.
3. Script 95–115 words, delivered 175–190 wpm, pitch range ≥14 st on hook + verdict.
4. A spoken CTA in every video (comment keyword / save / follow) — winners ask, losers don't.
5. Heading: "Name: outcome" or a descriptive benefit sentence. Sentence case.
6. TikTok description = ~2–4 keyword sentences (mini-article); link optional, hashtags ≤3.
   Other platforms keep their §9 shapes. Never copy one caption to all platforms.
7. Topic anchor: tie the tool to something the viewer already knows (Spotify, Windows,
   Claude…) in the first sentence.

## Limits
- YouTube deep decode (script/voice/cover) needs authenticated cookies; only listing data was
  used. Add `--cookies` support before the next YT-heavy study.
- Prosody is measured on creators' mixed audio (music bed included), so pitch ranges are
  relative comparisons inside this sample, not studio measurements.
- Wellx.tech's top videos are largely music-led (47 wpm in the Oct-07 study); they win on
  demo footage, a different (valid) lane — not copied here.
