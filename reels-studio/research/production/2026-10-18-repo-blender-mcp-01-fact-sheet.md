# Fact sheet — MCP for Blender Pro (repo-blender-mcp-01)
Checked 2026-10-18 (Karachi) against primary sources.
- Repo: github.com/anujasid/blender-ai-mcp-addon — "AI assistant and MCP server for Blender: visual chat, scene tools, multi-agent workflows."
- GitHub API 2026-10-18: 551 stars, 9 forks, created 2026-10-15, MIT, Python.
- README: Blender 4.2+ add-on ("mcp-for-blender-pro", release 1.0.0); 21 scene tools; Visual Studio workspace (chat, scene objects, viewport snapshots, approvals, task board); built-in MCP server (authenticated Streamable HTTP) for OpenCode and other MCP clients.
- Models: OpenAI, Anthropic Claude, Google Gemini, OpenRouter, OpenCode Zen, Ollama, custom endpoints.
- Agent team mode: manager breaks work down, workers perform scene operations, reviewers approve or return findings.
- Install: download mcp-for-blender-pro.zip from Releases; Blender Edit → Preferences → Get Extensions → Install from Disk; choose provider + model.
- Catches (spoken): release bundle targets Windows x64 first; needs Blender 4.2+; cloud models cost money (local Ollama avoids it).
