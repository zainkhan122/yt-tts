# Local previews

Full-length renders of `briefs/tool-seedance-01.json` and `briefs/tool-claude-tokens-01.json`,
produced by `tools/local_preview_render.py` (piper narration + the real `graphics/` stage).

These are **review artefacts**, not production deliveries: narration is piper, not the approved
chatterbox voice, and they carry no QA manifest. The cloud renderer produces the publishable pair.

Every scene is an animated archetype on the `velocity-black` stage — no screen recording:
hero + scan tick + dial + keep/drop waves + collision/quote + endcard.
