## 🔁 The Loop We Run Every Video

```
1. I write script + generate scene images  →  videos/video_XXX/
2. YOU: paste voiceover text into ElevenLabs → download voiceover.mp3
3. YOU: attach voiceover.mp3 in your reply to me
4. I assemble final.mp4 (Ken Burns + audio + optional text overlays)
5. I generate thumbnail + write title/description/tags
6. YOU: download final.mp4 + thumbnail → upload to YouTube
```

> **If you'd rather not attach audio files:** I'll give you a scene-by-scene CapCut assembly guide instead (exact timings, which image goes where). Both paths are documented in `01_content_pipeline.md`.
