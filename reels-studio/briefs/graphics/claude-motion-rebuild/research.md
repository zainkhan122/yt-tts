# Claude Motion fact and visual provenance

- Official documentation: https://support.claude.com/en/articles/17454997-get-started-with-claude-motion
- In a chat, select Output then Motion or simply ask for an animation. Claude builds an artifact as code animating text, charts, shapes and images; it does not generate photoreal footage.
- Ask Claude to edit a detail, and export to MP4. Beta is on Team and Enterprise; an Enterprise owner may need to enable it.
- Creative visualization is an original animated reconstruction. It is not a capture of a Claude session and does not claim to show actual output. All numbers are illustrative sample data. Screen labels make this explicit.
- Source TikTok discovery: https://www.tiktok.com/@ai_vanta_ai/video/7712097301258374439. No source footage copied.
