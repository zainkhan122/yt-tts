# Local previews

Only the current Seedance preview metadata is retained. A local MP4, when present under
`renders/tool-seedance-01/`, is a review artifact, not an approved production delivery. The
local preview uses Kokoro, not the approved Chatterbox production voice. See
`../HANDOFF-GRAPHICS-CURRENT.md` for current renderer details and limitations.

Older preview artifacts and their tracked metadata were removed at the owner's request.
