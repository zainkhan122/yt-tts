# Scout (outcrawlai/scout) — fact sheet (checked 2026-10-16)
Sources: GitHub README + API (2026-10-16T08:20Z): 867 stars, 27 forks, created 2026-10-13, Apache-2.0.
- Open-source browser agent: describe a task; it reads, clicks, types, scrolls in a real browser and reports back (or says what is missing).
- Install: npm i @outcrawl/scout (Node 22+). Needs an Outcrawl key (free tier 1,000 credits/mo per README) plus any chat-completions model key, or a local model endpoint.
- Catches spoken: smoothest experience is Outcrawl's paid cloud; two keys to start; sites may still block bots.
