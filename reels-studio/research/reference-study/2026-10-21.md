# Reference study: 2026-10-21

Purpose: learn how real creators make short AI-tool videos before we make ours. We learn from
their delivery (title, script, hook, description, hashtags, media). We do not copy wording, formats
or structure. Each new short starts from a judgment about what is worth making, not from a template.

Baseline data: `research/social/decode-2026-10-18.json` (48 entries, 16 accounts; 32 top-tier,
16 bottom-tier) and `decode-2026-10-18.md`. Sample is small. Treat all numbers as directional.

### Delivery patterns worth learning from
- **The product is shown early.** Top videos put the real product or result in the first frame,
  not a logo or an intro. Face channels pair a face with one symbolic visual.
- **The first spoken sentence names the thing and what changes for the viewer.** Winners open
  with a claim about the viewer's world. Losers open with vague framing.
- **Captions are large and sparse** (2–4 words on screen), so the video works muted.
- **Titles are plain and specific.** Sentence case, the tool's name, the benefit. No caps shouting.
- **Descriptions on TikTok are keyword sentences**, not link dumps. Hashtags are few.
- **The same video performs very differently per platform** (one example: 149K views on TikTok,
  228 on YouTube Shorts with identical content). So the package must be adapted per platform.

## What this means for our production (judgment, not templates)
1. Choose a topic because it is worth a viewer's time: a real capability, a verified change, or
   a news item with a clear consequence. Do not pick it because it fits a category slot.
2. Open on the viewer's problem. Show the tool doing the thing in the first 2–3 seconds.
3. Use the product's real media first: screen captures, the owner's test runs, the repo's own
   images where licensed. Add an animation, chart, sticker or stat only when it helps the point.
4. Do not default to scrolling a repo page or showing a README. A README is evidence, not a show.
5. Keep captions clear of media. Keep the spoken script to about 95–115 words at 175–190 wpm for a
   spotlight. Length follows the material, not a quota.
6. Include a spoken next step only when it is real (for example, "try it on your next project").
7. Write each platform's title, caption and hashtags from scratch. Hashtags are niche only.

## Limits
- YouTube deep decode needs cookies (not available). Only listing data was used for YouTube.
- Pitch numbers are measured on mixed audio with music, so they are relative comparisons only.
- Wellx.tech's winners are music-led demo videos. That is a different lane. We observe it, we do not copy it.
- Hook labels were produced by a classifier and checked by reading; the labels are approximate.
- No free-credit offer, deadline or price was verified against an official page in this study.
  Those need an official-source check before any video uses them.
