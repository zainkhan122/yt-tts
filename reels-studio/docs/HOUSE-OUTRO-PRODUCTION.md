# House outro in Short production

Reference: the delivered GTA6 Clipper and MoneyPrinterTurbo Shorts end with the `YOUR CALL` house card, Hypeless logo and handle, pink Follow button, a topic-specific COMMENT keyword, cursor press, voice CTA and narration-aligned house captions. The visual component alone is not the complete outro. Do not shorten it to fit an arbitrary duration gate or append it silently.

For the graphics stage renderer, use its endcard scene and the shared `graphics/outro.js` + `graphics/templates/shared.js` contract with the CTA in the script. Confirm the voiced CTA, synchronized word captions, cursor and full outro in the finished MP4.

For custom/off-pipeline renders, generate the CTA in the established Chatterbox Option-3 house voice and obtain aligned word timings via `tools/one_go_review.py`; then use `tools/append_house_outro.py` with the exact body duration, WAV, timings, keyword and input/output files. The body remains the approved content; the CTA is additional. Example syntax is in that tool's help. The tool uses the shared card, caption and brand assets. Always inspect the finished MP4 and audio, run production QA against an updated full-length manifest, and repin final MP4, cover and review before any scheduling.

## Mandatory delivery gate

All managed new Short deliveries, including custom-rendered files, are blocked unless `research/production/outro-receipts/VIDEO-ID.json` records a completed audiovisual review of the exact released MP4 digest under `hypeless-narrated-outro-v1`. The gate is checked before queue approval, before Buffer `createPost` (including pilots), before Buffer media replacement, and before direct YouTube upload/scheduling (including the pilot). Missing, incomplete, too-short or mismatched evidence fails closed. Replacing the MP4 invalidates the receipt. Existing provider schedules are not modified by this change; they remain as scheduled.

Watch and listen to the complete finished MP4, including the full outro; verify the house layout, actual logo, Follow and COMMENT keyword, cursor movement, spoken CTA, synchronized captions, and untruncated finish. Only after this inspection, create the receipt with `python tools/certify_house_outro.py --id VIDEO-ID --video FINAL.mp4 --outro-start SECONDS --keyword KEYWORD --reviewer production-reviewer --confirm WATCHED_AND_LISTENED_TO_FULL_OUTRO`. The certifier decodes the whole file and checks duration and audio-track presence; the required audiovisual judgments are reviewer attestations, not automated recognition or proof. Commit the receipt and make sure its video hash equals the release digest before approval. Never create a PASS receipt for an uninspected file. The gate protects repository-managed workflows; it cannot police manual uploads outside them.
